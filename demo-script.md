# Quick Demo Script for Book Writing Assistant

## Demo Flow:

### 1. Open Extension (2 minutes)
- Press F5 to launch development extension
- Open test-document.md in new window
- Run command: "Author-AI-Assistant.openBookWritingPanel"

### 2. Basic Chat Test (3 minutes)
Message: "Hello, I'm writing an educational book about web development"
Expected: Welcome response with context awareness

### 3. Markdown Formatting Test (3 minutes)
Message: "Can you give me a structured outline with headers, lists, and formatting?"
Expected: Response with:
- # Headers
- **Bold text**
- - List items
- `Code snippets`

### 4. Copy Feature Test (2 minutes)
- Hover over assistant message
- Click "📋 Copy" button
- Paste in test document
- Verify content copied correctly

### 5. Insert Feature Test (3 minutes)
- Place cursor in test document
- Send: "Give me 3 writing tips"
- Click "📝 Insert" on response
- Verify content appears at cursor

### 6. Code Block Test (3 minutes)
Message: "Show me a JavaScript function for organizing book chapters"
Expected: Code block with:
- Language header
- Copy/Insert/Create file buttons
- Proper syntax highlighting

### 7. Content Generator Integration (2 minutes)
- Click "📝 Open Generator" button
- Verify main panel opens
- Test both panels work together

## Total Demo Time: ~18 minutes

## Key Points to Highlight:
✨ Copilot-like chat interface
🎯 Context-aware responses
📋 One-click copy functionality
📝 Direct insertion to active document
🔧 Code block action buttons
📚 Integrated with content generator
💪 Robust error handling
